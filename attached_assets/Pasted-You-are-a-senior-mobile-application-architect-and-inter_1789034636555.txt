PHASE 3 — CENTRALIZED TRANSLATION ARCHITECTURE
==================================================

Create a clean localization structure appropriate for the project.

For example, conceptually:

locales/
  en/
    common
    settings
    navigation
    errors
    reader
    authentication
    ...
  ar/
    common
    settings
    navigation
    errors
    reader
    authentication
    ...
  fr/
  es/
  zh/
  ...

The exact folder structure should follow the project's architecture.

Requirements:

1. English must be the fallback language unless the project already has a clearly established default.

2. Every translation must use stable translation keys.

3. Never use translated text itself as a key.

4. Avoid meaningless keys such as:
   "text1"
   "label2"
   "button3"

5. Use semantic keys such as:

   common.cancel
   common.confirm
   common.save

   navigation.home
   navigation.settings
   navigation.search

   settings.title
   settings.language
   settings.appearance

   reader.nextPage
   reader.previousPage

   errors.network
   errors.translationFailed

6. Support interpolation, for example:

   "chapter": "Chapter {{number}}"

7. Support pluralization where the framework/library supports it.

8. Keep translations organized and maintainable.

9. Make adding a new language require minimal work.

PHASE 6 — DEVICE LANGUAGE DETECTION
==================================================

On the first launch only:

1. Detect the device/system language using the appropriate API for the framework.

2. If the device language is supported, use it automatically.

3. If the device language is not supported, use the fallback language.

4. Once the user manually selects a language, the user's choice becomes authoritative.

5. Do NOT overwrite the user's manually selected language with the device language on future launches.

Conceptually:

First launch:
Device language → supported? → use it
                         ↓
                       no
                         ↓
                    fallback

Future launches:
Saved language → use saved language
