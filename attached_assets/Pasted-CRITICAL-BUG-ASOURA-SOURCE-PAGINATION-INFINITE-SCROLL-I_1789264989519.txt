CRITICAL BUG — ASOURA SOURCE PAGINATION / INFINITE SCROLL IS BROKEN

There is a specific functional bug with the Asoura manga/manhwa source.

Current behavior:
- Asoura successfully displays an initial group of manga/manhwa.
- The first batch of results is visible.
- When the user scrolls downward to load more results, NO genuinely new manga/manhwa appear.
- Instead, the same manga/manhwa from the first batch appear again/re-render/repeat.
- This happens repeatedly no matter how far the user scrolls.
- The user should be able to continuously load the next pages of Asoura results.

DO NOT treat this as a simple UI scrolling problem.

The reader scrolling itself is currently working and must NOT be changed.

This is specifically a SOURCE PAGINATION / DATA FETCHING / DEDUPLICATION / CACHE problem.

==================================================
RESULT APPENDING
==================================================

If page 1 returns:

[A, B, C, D, E]

and page 2 returns:

[F, G, H, I, J]

the final list must become:

[A, B, C, D, E, F, G, H, I, J]

NOT:

[A, B, C, D, E, A, B, C, D, E]

and NOT:

[F, G, H, I, J]

with page 1 disappearing.

The load-more operation must APPEND new results to the existing list.

It must not replace the existing list unless the user intentionally starts a completely new query/category/source.
